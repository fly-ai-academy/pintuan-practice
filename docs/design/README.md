# 拼团哇设计与原型

[Monorepo 工程设计与启动说明](monorepo.md)：先 Next.js，后 Nest.js。

[打开可点击 HTML 原型](拼团哇-可点击原型-375x812.html)。下载或克隆仓库后，直接用浏览器打开该文件，无需安装依赖。样式、插画和交互均内嵌，支持离线演示；产品文档链接需要网络。

也可在仓库根目录运行 `pnpm dev`，从首页进入原型。Web 启动和构建时自动从本目录复制 HTML，原型正文只维护这一份。

原型按 375 × 812 设计，包含 24 个页面。通过「场景与页面目录」切换页面、买家与团长角色，体验创建与发布、浏览选购、下单、模拟支付、截止成团或退款、模拟发货及确认收货。

原型覆盖整体产品流程；模板当前 v1.0.0 只纳入团长创建与编辑草稿、预览、确认发布和已发布详情，对应 A01～A04。原型中的其他流程仅作设计参考，不扩大当前版本的开发与验收范围。业务规则以 [产品目录](../product/README.md) 登记的飞书原文为准。

这是交互评审原型，登录、支付、退款和物流均为教学模拟，不连接真实服务。演示数据保存在当前浏览器的本地存储；切换预设场景或页面样例会重置演示数据。请选择示例测试地址。
